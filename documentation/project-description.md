# Project Description

## Project Name

HR Analytics Database

## Problem Statement

Organizations need an organized way to manage employee information, monitor performance, track promotions, and analyze salary changes.

## Solution

This project provides a relational database designed to store and manage HR-related information using MySQL.

## Database Design

The database follows a relational database model where employee data is connected with:

- Performance evaluations
- Promotion records
- Salary adjustments

## Relationships

The employee table acts as the main entity.

One employee can have:

- Multiple performance reviews.
- Multiple promotion records.
- Multiple salary increase records.

## Future Improvements

Possible future enhancements:

- Create a dashboard using Power BI.
- Add more HR analytics queries.
- Connect the database with a web application.
- Add employee attendance tracking.
